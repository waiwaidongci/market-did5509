# 001 初始表结构

应用首次启动以 SQLAlchemy 模型创建表与唯一约束。现有数据表只补建缺失表，升级到修改过字段的版本需要显式迁移。

- `users` 账号角色和加盐密码摘要。
- `datasets` 不可变记录批次，以名称和 SHA-256 去重。
- `runs` 记录参数、数据批次、运行租约、分析结果、导出文件及复核决定。
- `schedules` 保存定时计划和下一到期时间。
- `deliveries` 保存站内分发回执，每次运行最多一个回执。
- `audit_events` 记录登录、数据入库、运行、复核和报表分发动作。

## 九成等候（分片直方图）

- `wait_market_days` 市场日锚点，`(market, date)` 唯一；同一市场日的上报在此行串行对账。
- `wait_manifests` 封账单，`(market_day_id, batch_no)` 唯一；声明应到片号与封账总车数，内容以指纹固化，不可改写。
- `wait_shards` 门岗分片，`(market_day_id, batch_no, shard_no)` 唯一；只存「等候秒数 → 车辆数」的 JSON 计数，不保存单车。
- `wait_adoptions` 每个市场日当前采用的封账单、片号列表与九成秒数；齐备后在同一事务内切换。

分片/封账单重复上报按内容指纹判重：一致则忽略，不一致返回 409。采用批号只向前推进，旧批晚到不覆盖新批。
